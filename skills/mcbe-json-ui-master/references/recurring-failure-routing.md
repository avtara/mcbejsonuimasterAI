## Cross-cutting rules

1. Keep unrelated Sound, Animation, and Scripting log entries out of a UI fix unless their exact dependency path reaches the target control.
2. Preserve the complete control path and exact engine message. A screenshot alone cannot prove which inherited child owns an artifact.
3. Derive the supporting Skill from this table and verify any scenario evidence in the current checkout; do not invoke a missing tool or imply that a separate scenario catalog exists.
4. A static renderer must render a complete registered form root with a source-complete fixture. A fragment, shared placeholder fixture, blank output, unavailable pixel capability, or unsettled state is diagnostic only.
5. Evidence levels are ordered by capability, not prestige: `structural-static`, `final-pack-static-visual`, `calibrated-screenshot-comparison`, `bedrock-runtime-visual`, `bedrock-runtime-interaction`. Earlier evidence never substitutes for the catalog's minimum closure level.
6. Reproduce the reported failure at its primary owner. Use a focused regression when it can verify the behavior, and keep required device/state/runtime checks pending until exercised.

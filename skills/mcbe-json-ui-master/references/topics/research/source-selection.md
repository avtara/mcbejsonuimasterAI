# Source Selection

Choose source classes in this order:

1. Microsoft Learn for the documented surface
2. pinned Mojang samples for implementation evidence
3. target Bedrock runtime and Content Log for actual behavior
4. local sample packs for working patterns
5. community reference docs for rule explanations
6. a pinned Ztech snapshot for comparison/search only

When Learn and Mojang evidence conflict, preserve `unresolved-conflict`. Ztech is not official truth and cannot resolve that conflict.
